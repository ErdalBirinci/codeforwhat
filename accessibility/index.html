Accessibility statement

Version 2.0. Last reviewed November 2026. This statement covers the Todiste website and the audit report it delivers.

This site is a commercial service offered to consumers and businesses in the European Union, so the European Accessibility Act applies to it through the German Barrierefreiheitsstärkungsgesetz (BFSG), in force since 28 June 2025. This statement says what standard we hold ourselves to, what we tested, where we still fall short, and how to get a barrier fixed.

1. The standard we target

WCAG 2.2 level AA

We target WCAG 2.2 level AA, which is the level the harmonised standard EN 301 549 incorporates by reference for web content, and the level national laws — the BFSG in Germany, the RGAA in France, the AgID guidelines in Italy, the Accessibility Regulations in Austria — are enforced against. WCAG 2.1 AA is met as a consequence, since 2.2 is additive.

2. What we did

  • Every page is served as static HTML and renders without JavaScript. The sales page, the legal documents, this statement and the cookie policy are readable with scripting disabled.
  • A single <main> landmark and a skip link to it on every page, so a keyboard or screen-reader user does not traverse the navigation to reach the content.
  • Text contrast of at least 4.5:1 for body text and 3:1 for large text and interface boundaries, checked in both the light and the dark theme.
  • Nothing depends on colour alone; every state is also carried by text or shape.
  • The layout reflows to 320 CSS pixels without horizontal scrolling, and remains usable at 200% zoom (WCAG 1.4.4 and 1.4.10).
  • Visible focus indication on every focusable element, and no positive tabindex.
  • prefers-reduced-motion is honoured: the animated sections stand still when the operating system asks them to.
  • Form fields carry real labels and an autocomplete attribute, and an error is announced in text next to the field rather than by colour.

3. How it was tested

The site is checked with an automated pass on every deployment — landmarks, headings, labels, alternative text, focus handling, zoom and target size — and by hand with a keyboard-only run and a screen reader (NVDA on Windows, VoiceOver on macOS) for each new page. Automated testing finds a minority of barriers, which is why the manual pass is part of the release rather than an annual event.

4. Known limitations

  • The map-like visualisation of an audit uses scalable vector graphics with a text alternative; a screen-reader user gets the same findings as a table, but not the spatial layout, which carries no information the table lacks.
  • The PDF dossier is produced with tagged structure and a reading order, but a very long table of findings can still be awkward to navigate in some PDF readers. An HTML version of the same report is available on request at no cost.
  • The site's own audit engine reports a static marker score rather than a full conformance result. This statement is about the site, not about a claim of complete conformance: a manual audit against WCAG 2.2 AA is scheduled annually and its findings are folded into the list above.

5. Reporting a barrier

If something on this site is not usable for you, write to erdalbirinci@gmail.com with the page and what happened. Tell us the assistive technology you use if you are willing; it shortens the fix. We answer within five working days, and where the barrier blocks a purchase we complete the order with you by email in the meantime, so that an accessibility defect never costs you the service.

If the answer does not resolve it, you can ask for the response to be reviewed by the operator, and you can complain to the market surveillance authority responsible under the BFSG — in Berlin, the Landesamt für Gesundheit und Soziales — or to the authority in your own member state under the European Accessibility Act.

6. Enforcement and review

This statement is reviewed with every release that changes the interface, and at least once a year. The date at the top of the page is the date of the last review, not the date the page was written. A barrier reported and fixed is added to the measures above, so the next reader can see what changed.
