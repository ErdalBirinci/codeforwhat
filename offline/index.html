Verify a dossier in this browser

Choose the dossier JSON, or the stored audit file, that you were sent. The hash chain, the record digest and the HMAC seal are recomputed here, on this device. Nothing is uploaded and no server is contacted.

The file

Drop the dossier here, or choose it below. A PDF alone cannot be checked — its JSON is exported beside it for exactly this reason.

Without the key the chain and the record digest are still verified; the HMAC is reported as unchecked rather than valid.

    The same check from a terminal: npm run verify -- dossier.json --key ./data/operator.key. The seal is an HMAC-SHA-256 under the operator's key; the chain is chainn = SHA-256(chainn-1 | digestn).
